Этот репозиторий содержит Agent Skill, который учит модель не пересказывать тему целиком, а находить её **несущую конструкцию**: минимальный набор идей и связей, из которого можно восстановить остальное понимание.

> Сжимать следует не до заданного размера, а до момента, когда дальнейшее удаление уже ломает механизм или стирает важное различие.

## Что меняется в ответах

- сначала появляется короткая несущая мысль;
- факты связываются причинно, а не складываются в каталог;
- число опор определяется устройством темы, а не шаблоном;
- процессы раскрываются на одном сквозном примере;
- похожие понятия разделяются там, где смешение мешает пониманию;
- подробности добавляются только после того, как видна форма системы.

Скилл не делает каждый ответ искусственно коротким. Он убирает только то, что можно восстановить из уже показанной модели, и сохраняет детали, без которых модель перестаёт работать.

## Установка

Глобально для автоматически обнаруженного агента:

```bash
npx skills add likemetwice/skills --skill semantic-compression -g
```

Только для Codex:

```bash
npx skills add likemetwice/skills --skill semantic-compression -g -a codex
```

В текущий проект вместо глобальной установки:

```bash
npx skills add likemetwice/skills --skill semantic-compression
```

Посмотреть доступные скиллы до установки:

```bash
npx skills add likemetwice/skills --list
```

## Обновление

```bash
npx skills update semantic-compression -g
```

Для проектной установки используйте `-p` вместо `-g`:

```bash
npx skills update semantic-compression -p
```

## Пример использования

После установки задайте обычный содержательный вопрос:

> Объясни, почему кэш ускоряет систему и когда он становится источником ошибок.

Скилл направит ответ по траектории:

**ядро → причинный механизм → минимальные опоры → один сквозной пример → важные различия → границы применимости**

В результате вместо списка терминов должна получиться модель, по которой можно самостоятельно рассуждать о новом случае — например, выбрать между локальным кэшем, общим кэшем и отказом от кэширования.

## Структура репозитория

```text
skills/
└── semantic-compression/
    └── SKILL.md
```

Скилл использует стандартный формат Agent Skills и обнаруживается `npx skills` в каталоге `skills/`.

## Главный критерий

Хороший ответ не просто запоминается. Он показывает, **почему при данных условиях явление устроено именно так, какие части необходимы и что сломается при удалении каждой из них**.
